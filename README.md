# 🐍 Python Eğitim Notlarım ve Kod Örnekleri  

Merhaba! 👋 Bu repoda, **Python 101, 201, 301 ve 401** eğitimleri boyunca geliştirdiğim kod örnekleri ve projeler yer almaktadır.

## 📚 İçerik Hakkında  

Bu repository, eğitimler sırasında öğrendiğim **temel ve ileri Python kavramlarını pekiştirmek** amacıyla hazırlanmış uygulamalı kod örneklerini içerir. Kod açıklamaları Türkçe olarak eklenmiştir; bazı projelerde yorum satırlarında İngilizce notlar da bulunur. Böylece hem öğrenen hem öğretici bir kaynak sunar. 🌍

## 🔧 Eğitimler ve Projeler  

### 🐣 Python 101 – Temel Python  
- Değişkenler ve veri türleri  
- Koşul ifadeleri (if, else)  
- Döngüler (for, while)  
- Fonksiyonlar ve parametreler  
- Basit dosya işlemleri  

### 🐤 Python 201 – Orta Seviye  
- İleri fonksiyon kullanımı  
- List, tuple, set ve dictionary işlemleri  
- Dosya okuma/yazma  
- Hata yönetimi ve exception handling  
- Modüller ve paketler  

### 🦉 Python 301 – Nesne Yönelimli Programlama  
- Sınıflar ve nesne oluşturma  
- Constructor/Destructor  
- Miras (Inheritance)  
- Encapsulation ve metodlar  
- Örnek OOP projeleri  

### 🐍 Python 401 – İleri Python  
- Generatorlar ve iterators  
- Decoratorlar  
- İleri dosya ve veri işlemleri  
- Performans optimizasyonu  
- Karmaşık proje örnekleri
